## Brand & Style
The brand language fuses hyper-engineered avionics telemetry with executive luxury dark ergonomics. It addresses technical operators, mission controllers, flight engineers, and high-performance system architects who require instant visual telemetry alongside high-end physical hardware cues.

The design movement combines **Precision Avionics Glassmorphism** with **Brushed Metallic Skeuomorphism**:
- Surfaces emulate milled aerospace obsidian plate, precision-beveled titanium, and satin-anodized alloy frames.
- Key visual drivers: high-tension hairline borders with subtle metallic gradient angles, selective liquid-metallic specular highlights, and crisp monospaced HUD readouts.
- Visual cadence is controlled and disciplined: atmospheric dark depth punctuated by luminous avionics status signals and razor-sharp geometric data grids.

## Colors
The palette evokes an illuminated night cockpit cockpit console:

- **Core Canvases & Structural Tiers:**
  - Obsidian Base: `#0B0F14`
  - Elevated Plate: `#101620`
  - HUD Panel Surface: `#17202D`
  - Panel Float / Active Surface: `#1E293B`

- **Metallics & Specular Structure:**
  - Dark Titanium Border: `#333E4D`
  - Milled Satin Silver: `#4F5D73`
  - Silver Sheen Linear Gradient: `linear-gradient(135deg, #7E8C9F 0%, #333E4D 50%, #94A3B8 100%)`
  - Specular Hairline Accent: `rgba(255, 255, 255, 0.18)`

- **Avionics Signals & Luminescence:**
  - **Electric Cyan Primary (`#38BDF8` / `#0284C7`):** Primary interaction vectors, target vectors, radar sweeps, and active tracking frames.
  - **Aviation Orange Secondary (`#FF6B2B`):** System-critical callouts, engine throttle triggers, overrides, and live payload indicators.
  - **Telemetry Status Triad:**
    - Optimal / Viable: `#10B981` (Emerald Glow: `0 0 12px rgba(16, 185, 129, 0.45)`)
    - Advisory / Caution: `#F59E0B` (Amber Glow: `0 0 12px rgba(245, 158, 11, 0.45)`)
    - Alert / Breach: `#EF4444` (Critical Red Glow: `0 0 14px rgba(239, 68, 68, 0.55)`)

## Typography
Hierarchy hinges on the tactical intersection of two disciplined typefaces:
- **Space Grotesk:** Headlines, system titles, and instructional copy. Characters balance geometric aerodynamic forms with high screen clarity.
- **JetBrains Mono:** Dedicated exclusively to telemetry metrics, flight parameters, state descriptors, system coordinates, and metadata labels.
- Case Rules: All labels typed in `label-sm` and `label-md` enforce uppercase transform (`text-transform: uppercase`) with positive tracking to optimize terminal readability under low-light operating conditions.

## Layout & Spacing
The layout follows a rigid, calibrated instrument grid:
- **Layout Model:** 12-column fluid system on desktop (`min-width: 1024px`), 8-column system on tablet (`min-width: 768px`), and a 4-column column system on mobile screens.
- **Grid Discipline:** Telemetry modules lock to regular grid intervals. Flight-critical instrumentation prefers strict full-height column docking (`col-span-3`, `col-span-6`, `col-span-12`).
- **Scanline Pattern Underlay:** Master panels feature an ultra-faint repeating scanline texture overlay (`repeating-linear-gradient(0deg, rgba(0,0,0,0.15) 0px, rgba(0,0,0,0.15) 1px, transparent 1px, transparent 2px)`) to mimic high-resolution physical display monitors.

## Elevation & Depth
Depth emulates high-grade physical instrumentation modules encased in anodized flight racks:

- **Level 0 (Hull Substrate):** `#0B0F14` flat background with faint radial ambient glows beneath key telemetry zones.
- **Level 1 (Rack Chassis Panels):** `#101620` filled with 1px structural metallic borders (`#333E4D`), augmented by a top-edge 1px metallic specular highlight (`linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.25), transparent)`).
- **Level 2 (HUD Floating Instruments / Modals):** Semi-transparent `#17202D` at 85% opacity with `backdrop-filter: blur(16px)` and an ambient shadow: `0 16px 32px -8px rgba(0, 0, 0, 0.7), inset 0 1px 0 rgba(255, 255, 255, 0.15)`.
- **Status Luminescence (Glow Accents):** Active signals emit outer atmospheric radiance without muddying surrounding data:
  - Cyan Active: `0 0 12px rgba(56, 189, 248, 0.4)`
  - Alert Engaged: `0 0 16px rgba(239, 68, 68, 0.5)`

## Shapes
Aerospace avionics require structural corner discipline. Standard UI elements adhere to tight, precision-cut corners (`0.25rem` / `4px`). 
- Cards, data displays, and cockpit modules apply `roundedness: 1` (`4px`) to preserve structural grid density.
- Inner elements (pills, badges, toggle switches) may utilize chamfered corner cuts (45-degree corner clippings) or micro-radii (`2px`) for hardware tactical realism.
- Full pills are strictly reserved for live connection nodes, channel selectors, and hardware switch indicators.

## Components

### Buttons
- **Primary (Thrust Action):** Electric Cyan base (`#0284C7`) transitioning to `#38BDF8` on hover. JetBrains Mono medium text in `#0B0F14`, inset highlight `inset 0 1px 0 rgba(255,255,255,0.4)`, outer glow `0 0 14px rgba(56, 189, 248, 0.35)`.
- **Secondary (Titanium Plate):** Surface `#17202D`, 1px brushed silver border (`#4F5D73`), Space Grotesk text in `#F1F5F9`. Hover activates top-edge silver sheen and border tint `#94A3B8`.
- **Critical / Emergency (Override):** Aviation Orange `#FF6B2B` with contrasting deep obsidian text, pulsed radar ring border on critical states.

### Cards & Telemetry Pods
- **Structure:** Solid `#101620` chassis base with 1px border `#333E4D`.
- **Header Strip:** `#17202D` sub-header zone housing monospaced node identifiers (`SYS_01`, `ALT_VEC`) along with emerald or amber heartbeat status indicators.
- **Surface Accents:** Four-corner micro bracket graphics (`+` or hairline right-angle ticks) rendered in `#4F5D73` to frame data blocks.

### Data Chips & Status Badges
- Encapsulated monospaced text with `label-sm`.
- Darkened background plate (`rgba(16, 22, 32, 0.85)`) matched with a 1px perimeter glow in status color (Cyan, Amber, Emerald, Red).
- Prefixing icon: 6px circular LED indicator exhibiting high-luminance center core and radial glow.

### Form Inputs & Fields
- Dark well background (`#0B0F14`) framed with a recessed inner drop shadow (`inset 0 2px 4px rgba(0,0,0,0.6)`).
- Neutral border `#333E4D`; on focus, smoothly transitions to `#38BDF8` accompanied by a soft `0 0 8px rgba(56,189,248,0.3)` glow.
- Monospaced numeric inputs with integrated units (`M/S`, `PSI`, `DEG`, `KTS`) positioned as static labels on the right margin.

### Checkboxes & Toggle Switches
- **Checkboxes:** Square with chamfered styling, dark titanium frame, filled with solid cyan `#38BDF8` and an obsidian crossmark when active.
- **Flight Toggles:** Milled rectangular slider chassis (`#0B0F14`) featuring an extruded titanium handle (`#4F5D73` with vertical grip serrations) transitioning cleanly between dormant grey and active cyan/orange states.

### Data Tables & Lists
- Compact row padding (`space-xs` vertical, `space-md` horizontal).
- Alternating subtle scan-surface striping (`rgba(255,255,255,0.015)`).
- Right-aligned monospaced tabular numbers with uniform width (`font-variant-numeric: tabular-nums`).
- Active row highlights marked by a 2px left border strip in `#38BDF8`.
