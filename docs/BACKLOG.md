# AeroGrid Feature Backlog

This file tracks candidate features, extensions, and ideas not currently in the immediate sprint.

## Priority Differentiation Ideas (High Value for Differentiator Score)
1. **Explainable Scoring with Adjustable Weights**: Allow analysts to tune relative weights (runway vs. charging vs. hospital distance) and instantly see recalculations with breakdown transparency.
2. **Fleet-Aware Re-scoring Engine**: Switch between aircraft presets (e.g., Archer Midnight eVTOL, Twin Otter STOL, ATR-72) to dynamically adjust operational viability scores.
3. **Data Provenance & Quality Badges**: Visual inspection badges for every airstrip indicating source verification level (DGCA/AAI, OpenStreetMap, Satellite verified, or Unverified/Sample).
4. **Emergency / Air-Ambulance Critical Coverage View**: Isochrone/radius overlay showing coverage gaps to tertiary healthcare trauma centers.
5. **Smart Recommendation Engine ("Top 3 Strips")**: "Recommend top 3 airstrips for [Aircraft Model] in [State]" based on connectivity and catchment.
